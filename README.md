# 🛡 KomoVPN Bot — Telegram Bot for VLESS VPN Sales

Telegram-бот для продажи VPN на базе Xray с протоколом VLESS + XTLS-Reality. Полностью автономный: сам выдаёт конфиги, следит за трафиком, уведомляет об истечении подписки и блокирует превысивших лимит.

## Возможности

### Для пользователей
- **Пробный период** — 7 дней бесплатно при первом подключении
- **Покупка подписки** — 1/3/6/12 месяцев, оплата через баланс или ручным переводом
- **VLESS конфиг** — автоматическая генерация + QR-код сразу после оплаты
- **SOCKS5/HTTP прокси** — дополнительный прокси-протокол
- **Статус подписки** — визуальный прогресс-бар трафика, дней до истечения
- **Баланс** — пополнение через реквизиты, расход при продлении
- **GPT-поддержка** — AI-ассистент (Grok) отвечает на вопросы о подключении
- **MTProto прокси** — ссылка для обхода блокировки Telegram

### Для администратора
- **Управление пользователями** — список, статус, ручное продление, блокировка
- **Статистика трафика** — реальное потребление каждого клиента из Xray
- **Автоматика** — уведомления за 3 дня до конца, деактивация по истечении
- **Блокировка трафика** — автоматическая при превышении лимита
- **Сброс трафика** — ежемесячный сброс счётчика
- **Sync трафика** — синхронизация данных с Xray в БД

### Технические
- **Прямая работа с Xray** — управление клиентами через редактирование `config.json`
- **Несколько inbound** — поддержка multiple UUID на пользователя
- **Traffic reporter** — bash-скрипт для экспорта статистики

## Установка

```bash
git clone https://github.com/kurumi-mProject/vpn-bot.git
cd vpn-bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Установить Xray
bash install_xray.sh

# Настроить конфиг Xray
bash setup_xray.sh

cp .env.example .env
nano .env
python bot.py
```

## Переменные окружения (.env)

| Переменная | Описание | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен от @BotFather | `1234567890:AAB...` |
| `ADMIN_ID` | Telegram ID администратора | `123456789` |
| `SERVER_IP` | IP сервера (в конфигах клиентов) | `1.2.3.4` |
| `XRAY_CONFIG` | Путь к config.json Xray | `/usr/local/etc/xray/config.json` |
| `PUBLIC_KEY` | XTLS-Reality публичный ключ | `abc123...` |
| `SHORT_ID` | XTLS-Reality short ID | `a1b2c3` |
| `PRICE` | Цена за месяц (₽) | `250` |
| `TRAFFIC_LIMIT_GB` | Лимит трафика по умолчанию | `100` |
| `AITUNNEL_KEY` | Ключ для GPT-поддержки | `sk-aitunnel-...` |

## Схема работы

```
/start → проверка пользователя в БД
       ↓
Новый пользователь → предложение пробного периода (7 дней)
       ↓
Оплата → списание баланса / ручная оплата
       ↓
add_client_multi() → Xray создаёт UUID клиента
       ↓
Генерация VLESS-ссылки + QR-кода → отправка пользователю
       ↓
Планировщик:
  - каждые 6ч → check_expiring_users(3 дня) → уведомление
  - каждый час → check_expired_users() → деактивация
  - ежемесячно → reset_monthly_traffic() → сброс счётчика
```
